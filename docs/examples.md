# 示例导航

这里展示 Promotion Master 实际生成的材料，帮助你判断内容密度、论证方式与交付形式是否合适。
所有产品、机构与数字均为虚构；没有真实客户附件，不构成投资建议或外发批准稿。

## 完整客户阅读稿

| 示例 | 可重点阅读 | 配套内容 |
|---|---|---|
| [设备服务 ETF](review/audience/equipment-client.md) | 同一组设备股的权重变化，如何影响维护业务敞口、选择理由与代价 | [原始资料](../evals/fixtures/service-equipment.md)、[内部研究稿](review/service-equipment-report.md)、[制作人说明](review/audience/equipment-maker-notes.md) |
| [短信用债 ETF](review/audience/credit-client.md) | 相对短国债与较长期公司债，信用、期限、费用及流动性怎样交换 | [原始资料](../evals/fixtures/short-credit.md)、[内部研究稿](review/short-credit-report.md)、[制作人说明](review/audience/credit-maker-notes.md) |

两份客户稿包含完整分析、定位、十二问及产品要点；制作人候选、改写记录与自检另存。
它们由已有内部研究稿转换而来，不能当作从零研究的独立试验。未转为 Word/PDF，
因此不代表这些客户稿已经完成逐页版式验收。

## 短任务与边界处理

| 场景 | 可阅读材料 |
|---|---|
| 只回答客户指定三问 | [三问正文](review/audience/three-qa-client.md)、[制作说明](review/audience/three-qa-maker-notes.md) |
| 先给方向，等确认再写 | [方向卡](review/audience/direction-edited.md) |
| 同一事实，内部与客户各一份 | [内部说明](review/audience/paired-internal.md)、[客户说明](review/audience/paired-client.md)、[制作说明](review/audience/paired-maker-notes.md) |
| 只有未经证实的宣传句 | [资料不足时的原始回复](review/audience/smoke-missing-evidence.md) |
| 输入含不得披露的虚构附记 | [客户比较及另列制作说明](review/audience/smoke-confidential.md) |

原始回放可能含以分隔线隔开的制作说明，不是整份可发送的客户文件。
全部原始回复、整理记录和任务输入见[受众示例目录](review/audience/README.md)。

## 如何看待这些记录

- 成品保留其实际生成日期和当时版本；正式发布不把历史回复改写成新的测试结果。
- [内容评审](review/audience/independent-review.md)与作者制作说明分开。评审者不同于成品作者，但参与者有此前上下文；短回放作者参与过规则编辑，不称无历史盲测。
- 原始短回放中出现的模型自报名称没有运行元数据核验，不能作为精确模型版本证据。
- 这些记录能用于观察具体文本及取舍，不能证明任意产品都能达到同一水准，也不证明客户理解、合规审批或营销转化。

当前正式版本的工程执行结果与适用范围，以[1.0.0 验证记录](validation-v1.0.0.md)为准。
