# 产品研究与写作示例

本目录保留 Promotion Master 开发期间实际生成的虚构产品材料。
原始输入、成品、作者制作说明和后续评审分别保存；不是投资建议或外发批准稿。
完整导航见 [示例说明](../examples.md)。

## 内部研究稿

- [设备服务 ETF](service-equipment-report.md)：从收入结构、持仓权重、费用与估值解释产品选择。
- [短信用债 ETF](short-credit-report.md)：比较短国债、短公司债及较长期公司债的风险与补偿。
- [资料不足时的方向回复](direction-only-response.md)：处理缺乏证据的宣传句，提供方向后等待确认。

原始输入分别为[设备资料](../../evals/fixtures/service-equipment.md)和
[债券资料](../../evals/fixtures/short-credit.md)。它们与技能成熟示例使用不同数据，
但仍属于相同的两类产品机制，不代表任意行业泛化验证。

## 客户与配套材料

[受众示例目录](audience/README.md)提供两份完整客户稿、三问、内外配套、
资料不足和保密输入回复，并链接原始记录与后续内容评审。

## 历史状态保持可辨

原稿保留其当时的制作说明和版本信息。两份内部研究稿在后续审阅中作过局部修正：
短信用债摘要明确“成分债短，不等于到点还本或退出价值确定”；设备稿费用问答补入
正文已有的费用口径与净值回报说明。未因此把后续修正倒写成首次生成表现。

成品作者和评审者有此前上下文，部分维护者参与了规则编辑，不能称全新无历史盲测。
作者自报模型名称不等于运行环境审计证据。脚本、内容审阅及真实使用者试用分别记录；
话术没有经过真实客户沟通或营销转化测试。
