制作说明保留作者交付时“独立审阅未完成”的原始状态，后续结果单列于[独立评审](independent-review.md)，不将之后的审阅倒填为作者当时已完成。稿件没有转换成 Word/PDF，不能宣称完成客户稿的逐页版式验收。

## 较短任务与确认体验

| 场景 | 可阅读整理稿 | 原始回复记录 |
|---|---|---|
| 只要三个客户问题 | [三问正文](three-qa-client.md)及[制作说明](three-qa-maker-notes.md) | [原始三问回放](smoke-three-qa.md) |
| 尚未决定用途，先建议后暂停 | [方向卡修订稿](direction-edited.md) | [原始方向回放](smoke-direction.md) |
| 同事实、内外两版，各三问 | [内部版](paired-internal.md)、[客户版](paired-client.md)、[制作说明](paired-maker-notes.md) | [原始配套回放](smoke-paired.md) |
| 只有未经证实的宣传句 | — | [资料不足回放](smoke-missing-evidence.md) |
| 附件有明确不得披露的虚构附记 | — | [保密输入回放](smoke-confidential.md) |

原始回放文件是供维护者审阅的完整回复容器，可能在分隔线后含制作说明；不是可以整份发送客户的成品。配套与三问的正式示范已按原有边界拆文件，正文数字和论证未改。两条补测同样只作为原始审阅记录，不作为待发送客户附件。

审阅后仅作下列整理，不改写原始观察：

- 方向卡将“下行行情中的价格上涨幅度”明确为“收益率下降时的价格上涨幅度”，消除债券价格与收益率方向的歧义。
- 配套回复拆成三份文件；原始稿自报“GPT-6”没有运行元数据核验，整理后的制作说明不作精确型号声明。
- 三问正文与制作说明拆分。不会把原始容器无修改地称为已隔离的客户文件。

## 输入、执行与证据边界

两份完整报告的请求是：

> 范围和改稿方向已确认，请把这份内部研究材料另做一份给了解ETF的客户直接阅读的完整中文产品分析，保持研究深度，帮助读者理解产品和替代选择；主线请你推荐采用，候选另留给我。只依据附件，不联网，不做Word或经营KPI，不再询问。客户正文与给我的简短制作说明分别交付，原内部稿保留不改。

执行者分别获得[设备原始资料](../../../evals/fixtures/service-equipment.md)或[短信用债原始资料](../../../evals/fixtures/short-credit.md)、对应旧内部稿及新技能。没有提供预期客户终稿或评审答案。这里有意提供内部稿以测试版本转换，不是同输入从零生成的新旧模型因果比较。

五条短回放分别测试：明确客户版只答三题；未知用途只给定位方向；已确认内外配套且各三问；仅有无来源的“本金安稳，月月到账，比存款收益高”；完整债券资料加明确保密的虚构渠道代号及让利底线。后两项未将缺证据或保密内容转成客户卖点。实际请求与原始输入详见[运行记录](run-log.md)。

- 两份报告由不同执行代理完成，评审由报告作者之外的代理完成。代理均有本线程此前上下文，评审者也参与过早期规则诊断；不能称全新会话、盲评或真人客户测试。
- 五条短回复的作者参与过卫星规则编辑，明确属于维护者回放。未读取验收标准并不意味着无既往知识。
- 工程测试与语义评审分开记录；不能从关键词未命中推断不存在泄密，也不能从七次写作推断稳定成功率或营销效果。
- [八场景规范](../../../evals/audience-editions.md)是后续可复用测试设计。本次七次实际写作并不等于严格按规范完成八场景独立会话；本轮未重新执行“仅内部完整稿”及“问答卫星单独生成客户十二问”的精确场景。

所有数字来自虚构附件；没有联网事实核验、真实客户适配、合规批准或实际发送。完整工程与版本记录见[本轮验证](../../validation-audience.md)。
