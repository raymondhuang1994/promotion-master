## 对现稿的处理及复核

先依据原始资料独立完成客户稿，再通读内部稿核对与融合。核实了至少三项承重数据，结果一致：加权期限/久期/到期收益率为1.176年、1.091年、3.626%；评级AA/A/BBB为40%/43%/17%；两种比较的静态参考差为0.75与0.40个百分点；三十天折算约0.0616个百分点，对应观察期完整价差之差0.08个百分点。未发现需要纠正的原稿关键数字，没有采用无法追溯的转引数字。

| 处理 | 内容与原因 |
|---|---|
| 保留并重组 | 原稿的双向替代逻辑、基金不按两年归还本金、信用门槛不能保证避损、用款时损失承受要求，均改写为客户可独立阅读的论证 |
| 借鉴补强 | 原稿明确指出参考差不能全部归为纯信用溢价，以及限价与按时退出可能冲突；已补入正文第五节和第十问 |
| 不并入客户正文 | 候选比较、攻防训练表、访谈标签、内部取数单、F/R/C登记、自评和技能版本；重要风险及来源仍留正文 |
| 新增可读呈现 | 全部十二只债券明细；分配比率的计算；利率下降与利差扩大并存的假设；7%持仓在债券价格跌10%时约影响组合−0.70%的静态示例，均明确非预测 |
| 对方纠正我的 | 无已发现的数值错误；对照原稿后补强两项限定，不将其表述成新的产品优势 |

利差久期1.09年来自月报，未声称从逐券数据独立复算；也未用完整现金流重建逐券到期收益率。情景统一使用月报两位小数久期，0.50个百分点变动对应本产品价格约0.545%，正文按两位小数显示为0.55%。收益率减费不是预期回报；历史总回报未重复扣费或加分配；价差、折价和净值回撤未相加。
