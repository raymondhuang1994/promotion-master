- 默认仅安装主技能、显式安装全部技能、目标冲突保护和隔离目录安装已测试。

- 主技能独立入口在不依赖 NODE_PATH 的条件下构建成功。
- 五个技能通过 skill-creator 格式检查，并成功打包为独立技能包与提示词包。
- 示例 Word 共 9 页，已渲染并目视检查全部页面；结构检查 0 FAIL / 0 WARN。
- 文字检查 0 FAIL / 1 WARN：示例问答中的“是不是稳赚”触发慎用词提示，回答明确否定该说法，人工确认无需删除问题。

这些检查只证明相关脚本、示例和安装边界可运行，不证明所有未来报告的研究结论或营销效果。

## 内容行为验证

本轮使用完全虚构的原始资料，不使用真实客户附件。[全部测试成品与审阅](review/README.md) 已提供，供使用者验收。

| 场景 | 实际结果 | 边界或最弱项 |
|---|---|---|
| 同题设备 ETF，新旧完整成稿 A/B | 两稿承重数字独立复算吻合，均解释业务、持仓、价格与替代选择。B 的短答分层、四组追问、正负情景和成本场景区分更明确 | A 的开场更形象，也有 B 未使用的全样本经营复算；B 更长，不能称全面胜出 |
| 新版短信用债完整成稿 C | 独立复算吻合；解释短国债、短公司债、较长期公司债的不同取舍，未沿用 AI 产业链口号 | 摘要“退出日期短”表述不准，需要改成到点还本及退出价值的边界；真实试讲未做 |
| 新版稀疏输入方向确认 D | 保留原句作为候选但不背书，提出三个方向、必要数据与推荐，停在确认点 | 只验证该次输出，不能从一句“不联网”反推所有执行环境行为 |
| 独立内容评审 | 由作者之外的代理逐条引用稿件，核对计算、判断、定位、问答与反证，提出小范围编辑建议 | 不是合规批准、真实客户反馈或营销转化测试 |

执行者收到原始资料和任务，不收到评审期待结论；可以阅读各自技能要求的示范。原计划隐藏版本标签，但实际稿件的交付说明含版本信息，故本轮只能称独立对比评审，不能称严格盲评。代理有先前上下文，不是全新无历史会话；两个资料机制也已在技能示范中出现，不证明任意产品泛化。原稿与之后的小范围修正分开记录，详见评审目录。

GitHub 上的预览自动检查已通过：[首次预览运行](https://github.com/raymondhuang1994/promotion-master/actions/runs/36082599195)，覆盖隔离安装、全部自检、源码无意外修改检查和预览包构建。CI 不代替人工内容审阅。
