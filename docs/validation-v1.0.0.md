- 默认文字安装在独立临时目录完成，只创建主技能链接；未要求 Word 工具链。
- `--all --with-word` 在另一个临时目录完成五入口安装；本地依赖解析和 doctor 通过。
- `bash tools/selftest.sh --all` 完成：54 项自动测试全部通过，共享文件一致。
- 测试包含 14 项安装行为与 15 项实际打包检查；两者是 54 项的子集，不重复计数。
- 五个技能均通过 Codex skill-creator 的格式校验。
- 主入口、Word 专项入口和共享渲染入口均实际构建 DOCX；同一输入两次构建的 `word/*.xml` 一致。

- 从实际生成的主技能 ZIP 解压至独立临时目录，安装包内 Node 依赖，并在取消 `NODE_PATH` 后用包内脚本成功构建 DOCX。
- 包内许可、Codex 元数据、递归模板和引用资源有检查；缺资源、本机绝对路径、符号链接和混入的旧产物有负面测试。依赖目录和私有资料不进入分发包。

环境：Python 3.9、Node.js 26.9.0、docx 9.6.1，以及本机 LibreOffice、Poppler、Pandoc 和中文字体。
