# 材料核查（material-factcheck）

## 什么时候用，什么时候不用

用：拿到一份路演材料、单张、新闻稿或 KFS，需要在对外或写报告之前确认数字能不能用、内部口径是否一致、哪些说法要改。也用于完整报告的阶段 1 到 2，此时产出直接进 `work/facts.md` 与 `work/recalc.md`。
不用：写完整报告（promotion-master）；写口号（product-slogan）；写话术（sales-qa-battlecard）。

## 原则

1. **图表要读底层数据，不读文字层。** 饼图、柱图的数值只在图表对象里，文字提取拿不到；用 `scripts/extract_pptx.py` 抽出来，再把图表页渲染成图片看一遍。
2. **可计算的宣称独立复算，披露事实回到原始文件。** 地区分布、行业分布、前十大合计、费用总额等，用明细和 `scripts/quant_tools.py` 复算；上市日期、指数规则等核对官方文件，不编造“独立算出的日期”。对不上写差多少及可能口径，不能验证的写未核对。
3. **矛盾单列，不埋在段落里。** 每条矛盾写清：材料 A 说什么、材料 B 或加总说什么、差多少、本备忘以哪个为准、建议向谁确认。
4. **核事实及其支持范围，不做产品价值判断。** 备忘不写“产品好不好”；检查数字是否正确，以及是否足以支持材料中的比较和结论。算对不代表推论成立。将结果交给定位/话术时同时给“能支持什么、不能推出什么”。
5. **数字带页码与日期。** 材料里没写日期的数字，标“材料未注明日期”，列入待确认。

## 工作流

**步骤 0　确认核查范围。** 完整材料、指定页或指定数字按用户要求执行；已有明确范围和授权不重问。核查任务不生成创意方向卡，不把只核数字扩大成报告或营销稿。

**步骤 1　抽取。** 运行 `python3 scripts/extract_pptx.py 材料.pptx out.json`，得到每页标题、文字、表格与图表数据；PDF 用文字提取加逐页渲染。把图表页渲染成图片逐页看，确认抽出的数字与图上标注一致。
**步骤 2　事实清单。** 按 `assets/memo-template.md` 第 1 节的表格逐条登记：事实 F 编号、页码、日期、级别（`references/evidence-discipline.md` 的 L1 至 L5）。完整材料核查覆盖费用、集中度、地区/行业、指数规则、上市信息、结构与复制方式；部分任务只核相关承重事实。只准附件或禁止联网时遵守限制，注明未外部核实，不用记忆补缺项。
**步骤 3　复算。** 按范围选择：地区与行业分布逐只加总对饼图；前三大、前十大、HHI、有效持股数（`quant_tools.concentration`）；权重上限与实际最大权重；费用（管理费、经常性开支估计与上限、是否含掉期费）；同一指标的内部一致性。计算以 R 编号关联输入 F，算法与输入写进备忘第 2 节；不为指定一项核查扩做全部。
**步骤 4　矛盾、推论与慎用词。** 差异超过四舍五入能解释的范围（单只权重四舍五入到 0.1% 时，n 只加总误差不超过 0.05n 个百分点）列为待解释矛盾。另查量纲与比较对象、相对权重和绝对权重、指数基日/发布日/基金成立或上市日；有来源但不足以支持的结论单列，不能只查数字或词语。对照 `references/caution-words.md` 记录命中页码与语境。
**步骤 5　待确认清单与交付。** 第 5 节列出需要向产品、指数公司或合规确认的问题，每条写谁能回答、影响哪个数字。备忘在对话内交付；也可写成 Markdown 文件。备忘顶部写材料名称、版本或日期、核查日期。

## 判定标准与常见矛盾类型

见 `references/checklist.md`：矛盾类型（图表与表格加总不一致、两页同一指标不一致、规则上限与实际权重不一致、估计值当实际值、回测当实盘、口径未注明）、每类的判定方法与写法。

## 与其他技能的关系

备忘是 product-slogan 与 sales-qa-battlecard 的事实来源；在 promotion-master 中，本技能对应阶段 1 与 2，产出写入 `work/facts.md` 与 `work/recalc.md`。四个技能可以单独用，也可以由 promotion-master 一次调用全部。

## 参考与脚本

| 文件 | 何时用 |

| `scripts/extract_pptx.py` | 步骤 1 抽取 PPT 文字、表格与图表数据 |

| `references/checklist.md` | 步骤 3 到 5 的判定标准与矛盾类型 |
| `references/evidence-discipline.md` | 事实分级、转引与复核、数据缺口写法 |
| `references/caution-words.md` | 步骤 4 慎用词扫描 |
| `assets/memo-template.md` | 交付格式 |
