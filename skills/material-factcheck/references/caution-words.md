# 慎用词表（团队共用）

用途：写口号、话术、问答、报告时先过一遍；材料里已出现的，点名页码，只在小范围沟通。与 `text_qa.py` 的 CAUTION 列表对应，改这里也要改那里。原则只有三条：不承诺，不绝对，不误导。

| 表述 | 问题 | 建议替代 |
|---|---|---|
| 首只、唯一、独家 | 要逐项核实，且随时可能失效 | “截至某日检索，香港市场未见同类产品（检索范围：……）” |
| 全面覆盖、均衡布局、三地均衡 | 与集中度事实冲突 | 直接给前三大占比、有效持股数，讲成核心—卫星结构 |
| 纯某主题、纯 AI 敞口 | 综合型企业占比不小，没有收入穿透 | “按主营业务归类，非收入穿透” |
| 持久定价权、永久护城河 | 周期性行业没有永久 | “当前定价权的证据与边界” |
| 稳赚、保本、零风险、低风险、更安全、更分散 | 承诺或误导 | 删除；用波动率、回撤、集中度数据说话 |
| 任何情形都受益、进可攻退可守 | 不成立 | 分熊、基准、牛三情景说明 |
| 回测高收益、排行榜式比较 | 回测不是实盘，且有选样偏差 | 回测与实盘分开，标基准日与发布日；比较带口径与日期 |
| 必然、一定、保证收益 | 承诺 | 删除 |
| 最佳、第一名、龙头（无口径） | 没有口径的最高级 | 带口径与日期的排名，例如“按某指标、某日期” |
| 错过就没有、最后机会、再不买就晚了 | 制造紧迫 | 删除 |
| 类比存款、收息、固定回报 | 误导产品性质 | 删除 |
| 对杠反或短线客户说“毕业产品”“换一个持有期” | 可能构成转换建议 | 须合规审阅，加“不构成转换建议”，只做投教 |
| 对同业的负面推测（策略失败、快清盘） | 无证据，有法律风险 | 只引用已公开事实并注明查证日期 |
