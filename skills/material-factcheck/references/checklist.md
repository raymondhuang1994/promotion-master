# 核查清单与矛盾类型

示例用虚构产品「北极星东南亚数据中心基础设施ETF」；真实核查以材料为准。

## 1. 承重事实必核项

| 项目 | 从哪里找 | 用什么对照 |
|---|---|---|
| 费用：管理费、经常性开支估计与上限、是否含掉期费、其他一次性费用 | 产品页、KFS | KFS 与章程；两处数字要一致 |
| 集中度：前三大、前十大、最大单只、有效持股数 | 成分股表 | `quant_tools.concentration`，自己算 |
| 地区与行业分布 | 饼图（底层数据） | 成分股表按交易所或行业逐只加总 |
| 指数规则：成分数、加权、上限、调整频率、基准日与发布日 | 指数页 | 指数公司规则文件；上限与实际最大权重比较 |
| 上市信息：日期、每手、门槛、交易币种、非上市类别 | 产品页 | 交易所公告 |
| 历史业绩 | 指数说明、基金业绩页 | 分清指数基日、发布日、基金成立日、上市日；基日是计算起点，不代表实盘。发布前指数历史通常为回溯计算，按指数公司披露标注；发布后指数实时记录与基金实际净值分别列示。基金实际净值以官方披露的成立/业绩起算日为准，交易表现以上市交易日为准 |
| 综合型成分股 | 成分股表 | 主营业务归类，标“非收入穿透”，估算占比 |

## 2. 矛盾类型与判定

| 类型 | 判定方法 | 写法 |
|---|---|---|
| 图表与表格加总不一致 | 逐只加总对饼图底层数据；差异超过 0.05n 个百分点（n 为加总只数）即矛盾 | “第 5 页饼图 X%，第 29 页逐只加总 Y%，差 Z 个百分点，超出四舍五入范围；可能口径：注册地对收入来源地、分类版本不同” |
| 两页同一指标不一致 | 全文检索同一指标 | 两页页码、两个数字、差异 |
| 规则上限与实际权重不一致 | 上限 20% 对最大权重 21.0% | “上限在调整日实施，其后漂移；写法应为‘上限为 20%’而非‘不超过 20%’” |
| 估计值当实际值 | 找“估计”“预期”“约”字样 | 上市前门槛、经常性开支估计，一律加“估算”标注，并写更新时点 |
| 回测当实盘 | 对照指数基日、发布日、基金成立或上市日及数据口径 | 分开列指数回测、指数实时记录、基金实际净值/交易表现；不能把发布后的指数历史冒充基金业绩 |
| 绝对权重当相对倾斜 | 是否同时取得双方同日权重；费用与收益是否同口径 | 相对贡献使用两者权重差；没有竞品权重不报费用覆盖阈值 |
| 量纲或推论不成立 | 数据即使各自有来源，是否真的能支持结论 | 产业资本开支不是基金投资者需求，ETF AUM不是产业供给；二者不能相除推出产品空白或募资空间 |
| 口径未注明 | 数字无日期、无来源 | 列入待确认；对外前补日期 |
| 慎用词 | 对照慎用词表 | 页码、原文、替代写法 |

## 3. 四舍五入范围的算法

单只权重四舍五入到 0.1%，每只误差不超过 0.05 个百分点；n 只加总，误差不超过 0.05n 个百分点。例：15 只加总误差上限 0.75 个百分点；差 5.8 个百分点就不是四舍五入。饼图底层数据通常比标注多两位小数，先用底层数据比。

## 4. 写备忘时的克制

- 不写产品评价，不写“建议不要发”；只写“哪个数字不能这样用、改成什么”。
- 材料里的慎用词与矛盾，建议小范围向产品团队提出，不在大群指出。
- 无法核对的写“未核对”，不写“大致没问题”。
