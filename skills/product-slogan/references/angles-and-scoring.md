# 方向、候选与评分

本文件的「北极星东南亚数据中心基础设施ETF」和所有数字均为虚构教学素材。代表句只说明写法，不证明产品事实，也不可直接用作真实产品文案。

## 1. 先区分方向，再写句子

叙事方向决定说服谁、回答什么问题、用哪条机制与证据；句子变体只改变节奏、用词或比喻。先交方向对比并等待选择，已有方向或明确授权直接执行时沿用，详见 `direction-confirmation.md`。默认 3 个方向不必固定为下表三种，应从当次产品和客户问题重建。

进入精修前先有准确的一句话定位：读者能识别产品的角色、针对的需求、相对替代方案的
选择理由与决定适配的条件。句式不限，不为短而删去承重条件；需要时主句后附一句条件。
例如先说明“为明确希望增加某类区域敞口的人，提供按规则持有该类资产的工具”，
再根据实际证据补充比较理由；不能从“按规则持有”直接跳到“更安全”“更值得买”。
没有独有优势也可以诚实定位品类价值，不能把缺乏差异用修辞掩盖。

| 方向示意 | 代表句（仅示范风格） | 要证明什么 | 适用场景与取舍 |
|---|---|---|---|
| 产业位置 | 算力扩张，先看机房底座 | 需求如何变为企业收入；指数是否实质覆盖该环节及其权重 | 主题教育、建立记忆；比喻可能掩盖资本开支与盈利风险 |
| 参与方式 | 将区域机房产业，放进一份配置 | 实际敞口、门槛和相对直接选股的便利 | 初次了解产品的人；便利往往是ETF共性，不能冒充独有优势 |
| 组合角色 | 给科技持仓，增加一种产业视角 | 与已有持仓的重叠、经济驱动差异及适配前提 | 已有相关资产的客户；不能未经验证承诺分散或降低波动 |

每张卡写证据状态、适用/不适用场景、推荐与牺牲了什么。两张卡若可以互换受众、机制与证据而不影响判断，就合并为一个方向，不为凑三项给同义改写。可推荐某方向进入验证，但须标清代表句尚未达到使用条件。

## 2. 传播表达、比喻与用户原句

- 一句话定位是准确表达的基准，多条传播候选比较客户入口、节奏、记忆点与误解风险。直述、对比、数字或比喻均可，不要求每条都有比喻；传播版不能扩大定位中的对象、范围或承诺。
- 原句逐字留存，附喜欢点（画面感、产业位置、力度等）、使用场景、保留级别 exact / spirit / reference。exact 保留原文并把候选另列；spirit 保留喜欢点再改写；reference 仅借鉴写法。
- 判断比喻映射的具体机制、覆盖范围、不能推导的含义。例如“底座”描述所处环节，不能自动推出不可替代、稳定盈利或低风险。
- 事实缺口与表达偏好分开处理。用户确认方向或要求保留原句，不等于事实背书；缺证据原句放“保留但暂不推荐”池，给所需证据与可用的收窄版本，不静默替换原文。
- 客户偏好留在项目记录，不收入公共样例作为默认口号；每次任务重新判断产品与受众。

## 3. 可选的六角度发散

选定方向后默认每个方向 3 到 5 条。用户要深入发散、或现有候选不能覆盖所选场景时，才选以下角度扩展，不要求全部做。

| 角度 | 出发点 | 证据检查 |
|---|---|---|
| 痛点型 | 跨市场操作、选股成本等具体问题 | 问题对目标客群是否真实；产品是否确实解决 |
| 品类命名型 | 用形象表达产业位置或产品角色 | 比喻与收入机制、指数覆盖是否吻合；哪些含义不成立 |
| 数字型 | 一个可溯源、可感知的数字 | 来源、日期、单位、口径；成分数量不冒充分散程度 |
| 对比型 | 与客户真正考虑的替代方案比较 | 同期同口径并指出对方优势；不同资产篮子不能说等量替代 |
| 行动型 | 指向读者可采取的下一步 | 动作与渠道、客户阶段相符；未确认功能不宣传月供等操作 |
| 身份认同型 | 说给特定持仓或需求的人 | 有适配证据，不把假想画像写成客户事实 |

## 4. 基础正确、核心营销质量与按需项

逐项写成品位置、观察与结论；如需比较候选，可记 0（缺失/错误）、1（有缺口）、2（充分）。
基础正确与核心营销质量分列，不相加成总分，不设靠高分抵消缺陷的推荐线。
事实不支持、表达有误导的候选不能推荐；判断与定位缺乏选择理由时先修内容，
不能靠来源、候选数、格式或语言版本齐全获得营销通过。未推荐项仍在制作人选择材料或底稿中保留并写原因；评分与取舍表不自动进入客户成品。

| 基础正确 | 充分的可观察表现 | 需退回修改的情况 |
|---|---|---|
| 证据与机制 | 事实支持整条句子的对象、范围和因果；定位的选择理由有事实与机制支撑 | 只有相关事实编号，无支持句子结论的推理；把主题增长当作产品收益 |
| 表达边界 | 不承诺、不绝对、不误导；短标题本身不暗示解释层又否定的含义 | 比喻夹带安全性或盈利暗示；必要条件被省略 |
| 范围与一致性 | 已选定位、候选、语言版本与 exact 原句有清楚对应，事实口径一致 | 擅改原句、候选失踪、跨版本改变投资角色或适配范围 |

| 核心营销质量 | 充分的可观察表现 | 需退回修改的情况 |
|---|---|---|
| 判断与客户价值 | 能说明该句改变谁的什么选择，理由落到实际产品及客户需要 | 只重述名称、主题或特征；无法解释为什么客户在乎 |
| 定位与比较 | 独立阅读能识别角色、受众与成立条件；有选择理由，品类共性与有限差异如实区分 | 换成任意产品名仍声称同样的独有优势；替代方案不明 |
| 理解与记忆 | 审阅者能用自己的话复述核心意思及必要条件，候选有适合该渠道的具体记忆点 | 必须看长解释才知道在说什么；记住修辞却误解产品 |
| 候选与取舍 | 推荐理由对应受众、场景和证据，不同候选有清楚的表达收益与误解代价 | 全是同义改写，或每句都被称为最好；只因有比喻就优先 |

研究型优先明确对象、条件和机制；传播型优先记忆和节奏，但沿用同一事实边界；双层用短标题配一句准确解释，两层不能互相矛盾。

可选项：需要产品家族时评延展性；要求多语时评各语独立成立且定位一致；香港口语渠道评粤语读音。单独记录，不适用写 N/A，不扣分。不因某句只适用于母产品、只需简体，就判为弱候选。

独立审阅者只拿已确认任务、原始事实和候选，不看作者的自评分；让其复述定位、指出
最容易误解的含义并比较最强替代，再按成品位置记录问题。作者自检、独立模型评审与
真实用户试读分别注明；未做用户试读，不宣称客户已经一次听懂或转化率得到提升。

## 5. 两个压力测试

**熊市测试。** 将候选放在“净值较上市回撤 30%”“同类产品规模反超”等假设标题旁边读。变成收益承诺或反讽的标“熊市失效”，说明哪层含义失效；描述产业位置的命名也须检查经济含义，不能自动通过。

**撞车检索。** 检索直接同业、指数公司、同主题基金近 12 个月宣传语，附来源和查证日期。相同句式或重合两个关键词只是复核线索，要比较是否为通用行业表述及整体含义是否相似，不能机械判定独创或撞车。不能联网标“未检索”，不能写“未见同类”。

## 6. 按需语言

- 语言范围沿用用户选择；未指定时按当前沟通与目标渠道提出默认，不自动输出简繁英全套。
- **简体**：按受众使用通用财经词，避免内部缩写。
- **繁体（香港）**：不是简转繁。用港式表达：“一手”“月供”“供款”“戶口”“上車”慎用（俚语，视渠道）；“基金”“指數”“成份股”按港交所与产品文件的写法；避免内地网络用语。
- **英文**：独立成句，动词开头或名词短语皆可；不用中文式排比直译；数字与货币写法按英文习惯（HK$1,200）。
- 三版可以不是同一句话的翻译，但要指向同一个定位句。

## 7. 交付检查

- 未选方向且未授权直接执行时，只交方向卡；已确认的不重问。
- 所有已生成候选与用户原句都有去向；未推荐项写原因和补证条件。
- 每条推荐能回答“证据为什么支持这句”；一个事实编号不能替代论证。
- 准确定位先于传播候选；推荐依据包含真实客户价值，不能只有比喻或记忆度。
- 基础正确与核心营销质量分别有结论，未解决的定位缺口没有被总分或流程完成度掩盖。
- 只交所选模块、语言、深度与受众版本；内部核心页和完整候选池分开，客户成品仅呈现所选表达及可读证据、必要条件，不夹带评分策略表。版本规则见 `audience-editions.md`。
