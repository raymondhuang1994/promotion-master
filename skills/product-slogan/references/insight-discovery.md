# 判断提炼：从材料多解释一步

用于已经确认范围的产品研究、定位与营销成稿。方向确认前只做有限预读和待验证假设，
不把此流程提前变成完整研究。短任务只处理相关问题，不为填表制造工作。

## 1. 先确定需要改变的认识

写出目标读者可能正在用的判断方式，以及它会造成什么选择困难。
客户访谈或材料没有证明的理解只能标为“待验证的客户假设”，不能冒充客户调研结论。
核心问题应当有可调查的对象与取舍，而不只是“产品有哪些亮点”。

按产品机制选择观察角度，不要求逐项完成：

| 观察角度 | 有用的追问 | 不能省略的下一步 |
|---|---|---|
| 价值归属 | 谁付款、谁获得收入、谁能留下利润，谁承担成本？ | 收入增长不等于利润增长，更不等于股价或基金回报 |
| 风险与补偿 | 较高收益来自什么风险、期限、约束或服务？ | 不能把承担的风险改名为免费优势 |
| 产品的真实形态 | 权重、条款和业务穿透后，实际暴露于什么？ | 不是把个别有趣成分当成整个产品 |
| 客户替代选择 | 与直买、已有工具、保留现状相比，究竟改变什么？ | 明确增量及代价，允许替代品更合适 |
| 时间与价格 | 新变化是业务兑现、预期变化，还是估值已反映？ | 没有价格证据不能把好业务推成好买点 |
| 执行条件 | 哪个渠道、工具或使用障碍真正限制了价值实现？ | 没有渠道数据不能凭规模小证明教育不足 |

产业、债券、现金分配或其他产品不必讲同一故事。好问题的形式可以借鉴，答案必须重建。

## 2. 从事实冲突生成候选判断

寻找有意义的差别：标签与实际敞口、收入与利润来源、客户关注点与结果驱动因素、
己方特点与竞品优势、历史表现与发生条件。差别必须来自 F/R，不强造反直觉。
对值得讲的候选，用下列五句完成一次推理：

1. 原本容易怎样理解？这是观察到的事实还是读者假设？
2. 哪些 F/R 增加或改变了这个理解？
3. 什么机制解释这些事实？是否存在同样合理的另一种解释？
4. 因而，怎样选择、比较或讲解产品才更准确？
5. 哪个事实缺口或反例会让这个判断失效？

这不是五个新的报告章节；长任务放底稿，成稿压缩成结论与必要支撑。
涉及相反解释时用可区分二者的证据做选择。缺证据就写条件性判断或待验证假设，
不因为用户喜欢某个方向就只寻找赞成材料。

## 3. 选择主线，而不是堆积亮点

优先选同时具备以下性质的判断：改变读者理解、有承重证据、产品确实承接、
对比较或使用有意义，并能说明不成立的条件。若缺少差异优势，准确解释品类角色也有价值，
但不得称为独有卖点。

完整产品推广报告通常选一个核心问题与三个左右互有分工的判断。数量是展示默认值，
不是发现配额；不要把同一判断换三种说法，也不要把“还应研究”写成已完成的研究结论。
各判断可分别解释机会来源、产品真实结构、相对选择或适配，但不固定成行业模板。

每条入选判断用“明确结论 → 最有力的证据 → 成立机制 → 对选择的含义 → 关键边界”写成。
证据足够就给清楚的有条件结论；不要每句都用“需要核查”收尾。
证据不足则明确缩小判断、补证或不推荐，不让传播力度高于证据承载能力。

## 4. 把判断转成定位和成品

先用普通语言写定位底稿：为哪类读者、提供什么实际敞口/能力、相对什么选择、
主要增量和代价是什么。再压成能讲的一句话；比喻只是可选表达，不是必需步骤。
默认给三个有实际取舍的候选、推荐一个，说明渠道或受众用途；按确认范围可增减。
客户稿通常不展示底稿字段编号，但来源必须可追溯。

同一主线应贯穿执行摘要、推荐定位、关键问答和一分钟话术。后续精修不能偷偷更换判断。
如果只会让标题更响亮，解释力没有增加，不算判断升级。

## 5. 定稿前的三个可观察测试

- **去修辞**：去掉比喻与形容词，能否说清判断、依据及对客户选择的含义？
- **增量解释**：与原材料摘要相比，多解释了什么关系或取舍？引用实际段落，不只说“更深入”。
- **最强反问**：读者最有力的反问是什么？现有证据能直接回答，还是需要收窄结论？

只评分词汇、字数或是否出现某句口号不能完成以上验收。
需要校准写法时读 `insight-examples.md` 中与本次机制相近的一例；学习转换方法，
不复制示例数据、专属定位或结论。证据不足与版式反例见 `examples/polaris-mini.json`，
它不是成熟营销成稿的文风上限。
