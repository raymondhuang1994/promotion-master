# work/ 工作区

长任务把本目录复制为报告目录下的 `work/`，短任务可在对话维护必要记录。
中断续写先读 `decisions.md` 与 `brief.md`，沿用实际已确认内容。含内部材料的工作区只存私有目录，不提交公开仓库。

| 文件 | 内容 | 写入阶段 |
|---|---|---|
| brief.md | 立项三问的答案、报告类型、水准参照 | 0 |
| facts.md | 事实清单（带页码或出处）与“材料有、结论没提炼”的素材 | 1、3 |
| claims.md | F/R → C 主张卡、叙事与候选、状态和跨成品更新 | 4–7 |
| recalc.md | 独立复算：算法、输入、结果、口径矛盾 | 2 |
| gaps.md | 数据缺口表；取数单的源 | 2、3、7 |
| outline.md | 章节骨架（结论式标题）与每章承重数字 | 4、5 |
| decisions.md | 用户拍板的每一项决定、日期、闸门自评分 | 全程 |

正文成稿写在 `work/report.json`，用 `scripts/build.js` 渲染；不要把正文写回构建脚本。
