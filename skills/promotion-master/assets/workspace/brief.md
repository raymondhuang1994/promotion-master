# 立项单

- 题目：
- 类型（A/B/C）：
- 读者与坦率程度：
- 交付形式：
- 数据能否补充：
- 水准参照（只参考写法与深度，观点独立）：
- 研究截点日期：
- 范围：完整分析 / 选做模块 / 优化现稿；包含与排除：
- 营销任务：客户现有选择、疑虑、希望改变的认识、渠道、下一步动作：
- 表达：研究型 / 传播型 / 双层组合；创意关闭 / 推荐方向 / 深入发散：
- 选定方向与理由（仅建议时不能写已选）：
- 原句、喜欢点、位置、exact/spirit/reference、证据状态：
- 用户实际确认回复与日期：
- 第二停点：仅核心方向改变 / 用户另约定先底稿后成稿：
