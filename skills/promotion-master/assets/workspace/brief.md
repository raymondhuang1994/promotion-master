- 题目：
- 类型（A/B/C）：
- 成品版本：内部使用 / 给客户阅读 / 两版配套；已明确 / 待确认：
- 最终读者、熟悉程度与使用渠道：
- 交付形式：
- 客户正文与制作人说明的交付位置；两版配套时各自文件：
- 数据能否补充：
- 水准参照（只参考写法与深度，观点独立）：
- 研究截点日期：
- 范围：完整分析 / 选做模块 / 优化现稿；包含与排除：
- 营销任务：客户现有选择、疑虑、希望改变的认识、渠道、下一步动作：
- 表达：研究型 / 传播型 / 双层组合；创意关闭 / 推荐方向 / 深入发散：
- 选定方向与理由（仅建议时不能写已选）：
- 原句、喜欢点、位置、exact/spirit/reference、证据状态：
- 用户实际确认回复与日期：
