# 高管版改写规则

适用于：用户要“高管版”“汇报版”“决策版”或“精简版”。

## 原则

高管版的目标，是让管理层觉得报告对业务有实际价值、有启发，并体现对市场足够的研究和理解。它保留结果，去掉过程。

## 做法

1. **删改清单先行。** 先列出准备删除、合并、改写的每一项及理由，用户逐项确认后再动手。不要随意删减。
2. **删去过程性内容**：验证过程、更正记录、思考过程、方法论自述、“不足与提升路径”一类的自我评估。这些可以留在工作底稿或单独的附件里。
3. **重构为“决策版正文加附录”**：正文只放判断、证据要点、选项与建议；明细、测算方法、来源清单放附录。
4. **保留完整的候选与选项。** 精简的是表述，不是选项；低优先级项保留并写明暂缓理由。
5. **不知道的内部事实留空。** 用户本人也不掌握的信息，先忽略或留空，不要编，也不要因此拖住进度。
6. **口径按官方披露。** 费率等数字以官方文件为准。
7. **标签克制。** 只标推断、假设、建议三类。
8. **版式要求提高**：排版清晰整齐，可直接交付；执行摘要两页内；每章开头一句结论。

## 常见新增内容

用户在高管版阶段常会要求扩展某个专题或新增“可以怎么做”的选项章节。新增内容同样走两步：先给结构与要点，确认后再扩写。
