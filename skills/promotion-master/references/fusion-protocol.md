# 融合其他稿件的规则

适用于：用户提供另一个 AI、同事或外部顾问写的同题稿件，要求借鉴或融合。

## 顺序

1. **先独立完成自己的版本。** 如果还没有独立版本，先做，再读对方稿件。用户要求“本轮独立研究、不整合”时，严格照做，等用户评估后再谈整合。
2. **通读对方稿件，做三栏清单**交给用户：
   - 可借鉴的：对方有、我没有、且有证据的内容；
   - 不借鉴的：与读者需求无关、证据不足或只是风格不同的内容，并说明原因；
   - 它纠正了我的：我写错或写得不准的地方，逐条承认。
3. **抽查核实。** 对方的承重数据至少抽查三项，优先选择会改变结论的。核实得了的，标明已核实；核实不了的，采用时标“转引，待复核”，并列入给用户的复核清单。
4. **立场冲突交给用户。** 两份稿件结论方向不同（例如一份偏营销、一份偏中性尽调），用选项形式请用户定基调，不要自行折中。
5. **骨架不变，证据层升级。** 保持自己报告的叙事主线，把对方的一手证据、量化工具、边界提示嫁接进来；不被对方的结论带走，只借鉴有价值之处。
6. **统一口径。** 两份稿件的数据时点不同的，按证据分级选定主口径，其余标日期并列。
7. **清理过程痕迹。** 融合后的正文不出现“上一版”“另一个 AI”等字眼；需要指称时统一写“参考研究”，并在附录说明其性质与哪些数据出自它。

## 给用户的融合说明

交付时单独说明四件事：融合了什么、没采纳什么及原因、哪些数字是转引待复核、对方纠正了哪些错误。
