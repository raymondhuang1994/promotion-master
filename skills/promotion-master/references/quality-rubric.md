# 质量验收：判断成立，使用者拿得走

按已确认范围验收；未选模块记 N/A 并说明，不因篇幅短而扣分。
把基础正确与核心营销质量分开记录。可用 0（缺失/错误）、1（有缺口）、2（充分）
辅助逐项比较，每项写成品位置、观察到的行为、缺口与修正；不合并成一个交付总分。
流程、结构或技术完成度不能抵消判断、定位或问答的缺陷。
自评不是独立审阅；模型模拟不能证明真实客户理解或营销转化。

## 基础正确：内容能否被信任和使用

| 项目 | 满足的可观察行为 |
|---|---|
| 方向与范围 | 内部/客户/两版看最终读者；先推荐并等待确认，或沿用已有授权；部分任务不膨胀，同事提出客户任务不误判内部 |
| 证据可追溯 | 承重事实有出处、日期、口径、核验状态；缺口未冒充事实 |
| 计算与比较 | 公式、单位、数据日期、比较对象与费用口径正确；测算条件可检查 |
| 偏好与一致性 | exact 原句未擅改；候选保留；各成品共用事实和主张，状态区分已选/建议 |
| 使用状态与边界 | 输出匹配所选版本；客户正文与制作人说明分离，关键限制与主张相邻，客户稿不冒充已批准发布 |
| 技术交付 | 所选格式可打开；必要 QA 实跑通过、图文可读；跳过和失败不写成通过 |

## 核心营销质量：是否形成值得传达的判断

适用于产品营销内容；机构研究、候选池研究按已选任务检查其判断与决策价值，
不额外要求口号、客户问答或十二问十二答。

| 项目 | 满足的可观察行为 | 常见失败 |
|---|---|---|
| 判断提炼 | 至少能指认所选范围内的关键判断，解释从哪些事实经什么机制得出、改变客户或管理层什么选择、什么事实会推翻它 | 把资料摘要、产业增长或产品特征直接写成买入理由；所有产品都能套用 |
| 产品与替代 | 主张落到实际持仓、规则或产品结构，并同客户真正考虑的替代方案比较；能说清为差异付出什么 | 主题成立就跳到产品值得买；把品类共性包装成独有优势 |
| 一句话定位 | 独立阅读可识别目标客户、产品角色与有依据的选择理由；决定适配的条件清楚，传播版未扩大原意 | 只有形容词或修辞；产品名一换仍声称同样的独有优势；准确解释要靠长篇补救 |
| 叙事与表达 | 推荐一个主线及必要支撑；候选体现不同客户入口或取舍；所选渠道的读者能从文字中复述主张、理由与代价 | 同义改写冒充方向；信息堆积；比喻暗示证据未支持的稳定收益或安全性 |
| 决策问答 | 完整产品营销报告默认十二问十二答，各题对应不同决策障碍；短答先回应该问题，再给依据与成立条件；最重要异议有能改变判断的追问 | 凑足十二行但问题重复；答费用却转讲行业前景；每题机械先认再推；用风险提示代替答案 |
| 反证与选择边界 | 最强反对理由得到正面回答；在证据不足、条件不合或替代更适合时明确收窄或停止推荐 | 只选容易回答的问题；缺证据仍坚持卖点；不适配只在附录出现 |

部分营销任务只查所选项：精修一句定位无需补完整问答；只回答三道异议无需扩成十二题。
没有真实访谈的问题按材料、替代方案或使用场景推导，在底稿记录为拟问；客户正文可用中性问答标题，不冒充真实访谈或市场统计。

## 按成品版本验收

详见 `audience-editions.md`。内部版验是否能支持研判和培训；客户版验其独立阅读体验，不以“换了人称”算完成。
客户读者应能从正文复述产品角色、主要依据和最大代价；术语有解释，主线清楚，所选深度没有被默认压成宣传单。
检查客户正文没有内部训练指令、策略/访谈隐私、F/R/C编号、制作过程、自评、候选评分表；删这些内容时没有连同承重条件、来源日期与实质风险一起删掉。
单独读标题、短答和图表也不产生正文已经否定的承诺。只有客户版时不额外交完整内部报告；两版分别交付，抽核主张、数字、日期、比较口径与失效条件一致。
脚本可以发现结构性遗失，不能凭敏感词零命中就宣布客户口吻合格；独立审阅需引用具体表达及可能误读。

## 阻断与待改

关键计算错误、捏造来源、无证据的承重结论、跳过用户要求的确认、
擅改 exact 项或泄漏内部材料，必须先修；任何总分都不能抵消。
核心判断没有成立、定位没有说明选择理由、关键问答没有回应障碍时，也应逐项退回修改，
不能以来源齐全、排版合格或检查项数量多而标营销验收通过。
尚有缺口可交明确标为“待完善”的底稿，写清哪些判断或话术还不能使用。
用户选了哪个范围，就按该范围检查，不要求为评分增加模块。

## 研究复核与独立营销验收

研究后先验事实、计算、机制、客户与替代；方向推翻时给选项并暂停。
最终再验表达、异议、原句保留及跨成品一致性。
完整产品营销报告在自检后增加独立营销审阅；有独立代理或审阅者时，提供原始材料、
已确认任务与方向、候选成品及本标准，不提供作者自评分或预设结论。请审阅者：

1. 用自己的话写出最重要的判断与一句话定位，指认支持它们的证据；复述走样时定位到具体表述。
2. 检查最强卖点的推理链，并提出最有力的替代选择或反证，判断成品是否正面处理。
3. 检查十二题是否对应不同障碍，重点试问最重要异议及一次追问；指出答非所问、隐含条件或应停止推荐的情形。
4. 逐项给通过/待改及成品位置、理由；修改后复核受影响的主张和表达，不用总分冲销问题。
5. 有客户版时先独立读客户正文再回核底稿；检查是否要靠销售提示才能理解、是否泄露内部内容，以及删繁后是否改变事实含义。两版配套另比对同一主张。

部分任务独立审阅其对应内容，不为审阅新增模块。无法独立审阅时明确记“仅完成自检，
独立营销验收未完成”，不能把作者换一个口吻的复查称作独立评审。
保留一页验收记录：检查项或 C 编号、自检/独立审阅、通过/待改、证据位置、问题与修正。
篇幅、图表数、新数字数、“惊人总结”数不是质量门槛。单一长报告的页数校准
只代表一个案例，不据此推断其他产品、渠道或短材料应当多长。

## 回放到最终成品

维护时用相同原始材料与任务验证方法变更前后：
1. 准备完整产品研究、局部营销材料、证据不足/明显不同结构产品等场景。
2. 新会话只给技能、任务与原始材料，不给终稿、预期答案或已知缺陷。
3. 首轮检查方向卡和停点；由测试者提供明确选择，再继续到最终选定成品。
4. 独立评审基础正确与核心营销质量，分别记录判断、定位、问答的实际表现；记录模型、版本、
   用户回复、实际输出、错误、证据位置与适用项结论。脚本测试与内容评审分开报告。
5. 比较同一场景的方法变更前后输出，修正有证据的失败。没有真实同事试用或成交数据，
   就不能宣称同事成功率或营销转化提升了某个百分比。

原始材料与终稿缺一时写明未完成对应金标准回放。仅有终稿不构成可重复研究的输入包。
私有金标准、真实附件及含内部信息的回放原文只在私有目录；公共 evals 使用虚构/可公开材料。
完全虚构输入的测试成品经隐私检查后可作为明确标注的评审样本公开；
真实材料测试只公开已检查无敏感信息的结果摘要，不因要展示效果而上传内部附件。
